## 加了什么

### 装扮（视觉预设）

调好的一套外观可以整份存下来，随时一键换回去。

- 设置 → 外观 → 最上面那格「装扮」：保存当前样式、重命名、用当前样式覆盖、删除
- 聊天输入框 `+` 面板第四格「装扮」：横滑一排卡片，点一张当场换
- 一套装扮包含 **89 项视觉设置** + 主题预设 + 动态取色：颜色、对白样式、字体排版、材质、插图素材、输入框全都跟着走
- **助手聊天背景图也在装扮里**，还可以跨助手应用：同一套装扮，换到哪个助手都能用
- 用到的图片会**复制一份副本**存进装扮，之后你换图、删原图都不影响已存的装扮
- **不包含**头像、昵称、Token 用量、思考折叠这些功能开关（这些不太方便啦）

### 提示词 / 世界书分组

人设写多了，提示词和世界书都会变成一长条滑不到底的墙。现在可以收纳：

- 每条提示词注入 / 世界书多一个「分组」字段，**填同一个名字就归到一组**
- 列表按组分块显示，点组头收起 / 展开，默认全部收起
- 组头右边：**↑↓** 整组上下挪、**铅笔**改组名（组里所有条目一起改）
- 组内长按条目可以拖动调整顺序
- 输入框 `+` 面板里同样分组，**每组一个总开关**，一次开一整组
- **展开状态会记住**：这次点开了哪几组，下次进来还是那样

### 按助手的压缩提示词

不同的助手适合不同的压缩策略（玩角色扮演要保住人设，聊剧情要保住时间线）。

- 设置 → 助手 → 点进助手 → 提示词 → 最底下「上下文压缩提示词」
- 留空就用全局那份；填了只有这个助手用它，**切助手自动跟着换**
- 注意：这里填的是「怎么压缩」的指令，必须包含 `{content}` 用来接收对话原文

### 颜色

用户气泡 / AI 气泡 / 聊天背景 / 输入框 / 主色调 / 正文文字色 / 时间文字色 / 对话回顾配色，全都能单独指定。

- 取色盘 + 最近用过的记忆色（最多 12 个）
- 主题基色：给一个颜色，按选的算法自动生成整套浅色 / 深色配色

### 透明度与材质

- 气泡、思维链、侧边栏元素、输入框、提示语、输入框文字，透明度各自独立
- 界面材质四档：**纯色 / 半透明 / 磨砂 / 液态玻璃**，界面、输入框、气泡可以分别选
- 磨砂与液态玻璃接到 haze 模糊，模糊强度 0–40 dp 可调
- 气泡实时模糊默认关闭（性能敏感，想要氛围再开）

### 插图素材

输入框 / 侧边栏 / 用户气泡 / AI 气泡，四处都能贴自己的图。

- 相册选图，自动复制进 App 内部目录，原图删了也不影响
- 不透明度、主题色遮罩、圆角分别可调

### 对白样式

引号里的对白可以单独拎出来上一套样式（其实我特别馋酒馆的美化，有借鉴哦）。

- 引号内的文字单独上色，行级底色可开关、透明度可调
- 三种下划线：实线 / 虚线 / 点线，各自能设颜色；端点贴字形轮廓，不会越出引号
- 行首竖线：高度、粗细（0.01 dp 一档）、左右位置都能调（这个做的不太好，因为没有现成的只能自己画）
- 外层符号：`「」`、`『』` 能单独上色、单独放大缩小；**符号还可以单独指定用系统字体**（很多中文字体缺这两个字形，系统会偷偷借字体来补）
- 只影响显示，原文、复制出来的内容一个字都不变

### 字体与排版

- 字体库：导入的字体存多个，随时切
- **界面字体**和**正文字体**分开选
- 界面字号 0.85–1.15 倍；正文字号几档预设，也能直接填百分比（10%–200%）
- 行距 0.8–2.0 倍、段落间距 -8~24 dp、字间距按 em 微调
- 首行缩进 0–4 格（小说排版），只作用在渲染层

### 输入框

- 自定义提示语，提示语透明度可调
- 最小高度、整体透明度、文字颜色
- 全屏编辑页：跟随聊天背景，或者单独指定背景色 / 背景图

### 其他

- 消息时间可以显示完整格式（`2026年1月1日 12:00:00`），也可以挪到昵称下面
- 头像大小 24–72 dp
- 扩展管理的标签顺序改成：模式注入 → 世界书 → 快捷消息 → Skills
- 自己的图标和名字：**Eternity**

## 自己编译

仓库里的 `.github/workflows/build.yml` 会：

1. 拉取上游 `rikkahub/rikkahub` 的 2.5.3（含子模块）
2. 打上 `beautify.patch`
3. 用 JDK 21 编译 release 版
4. 上传到 Actions Artifacts，并发布到 Releases

Fork 本仓库 → 打开 `Actions` → 选「编一个我自己的 Rikka」→ `Run workflow`，跑完就能在 Releases 拿到自己的包。

## 说明

- 每个版本都用自己的签名证书（存在 Actions 缓存里），所以后续版本可以直接覆盖安装
- 补丁是累计的：`beautify.patch` 里包含全部改动，直接整文件替换即可
- 补丁体积约 1 MB，大部分是图标资源和代码改动
